# Оплата и автоматизация — что и в каком порядке включать

Три независимых куска. Сайт (`index.html`) уже умеет открывать окно оплаты
CloudPayments — этого достаточно, чтобы принимать деньги. Всё остальное ниже
(бот + таблица + письмо) — надстройка над этим, можно включать позже, сайт от
её отсутствия не сломается: `onFail`/пустые секреты просто не отправят
уведомления, оплата при этом всё равно пройдёт и деньги придут в CloudPayments.

## 1. Подключить приём оплаты (обязательно, чтобы кнопки вообще работали)

1. Личный кабинет CloudPayments → «Настройки сайта» → скопировать **Public ID**
   (выглядит как `pk_XXXXXXXXXXXXXXXXXXXXX`).
2. В `index.html` найти строку
   `var CP_PUBLIC_ID = "ВСТАВЬТЕ_ВАШ_PUBLIC_ID";` и вписать туда реальный ID.
3. Готово — кнопки «Оплатить» на тарифах откроют виджет CloudPayments.

Secret-ключ (не Public ID, а именно секретный) сюда **не** вставлять — он
нужен только для шага 3 ниже, и живёт не в HTML, а в секретах Cloudflare.

## 2. Уведомление о новой оплате в Telegram + запись в таблицу + письмо клиенту (по желанию)

### 2.1 Google Таблица и письмо
1. Создайте новую Google Таблицу для учёта оплат.
2. Расширения → Apps Script → вставьте туда содержимое `apps-script.gs`.
3. Deploy → New deployment → Web app → Execute as: **Me**, Who has access: **Anyone**.
4. Скопируйте URL развёртывания — это `APPS_SCRIPT_URL`.

### 2.2 Бот-уведомитель в Telegram
1. В Telegram напишите @BotFather → `/newbot` → следуйте подсказкам.
   (Можно и через существующего бота клуба, но отдельный «служебный» бот
   чище — не путается с перепиской участниц.)
2. Получите **токен бота** (`TELEGRAM_BOT_TOKEN`).
3. Добавьте этого бота в чат/канал, куда должны приходить уведомления об
   оплатах (можно личный чат с самим ботом, можно отдельный канал для вас
   и Светланы).
4. Узнайте **chat_id** этого чата — проще всего: напишите что-нибудь в чат,
   затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` в браузере
   и найдите `"chat":{"id":...}` в ответе. Это и есть `TELEGRAM_ADMIN_CHAT_ID`.

### 2.3 Сам Cloudflare Worker
Нужен бесплатный аккаунт на cloudflare.com и установленный `wrangler`
(`npm install -g wrangler`, если Node.js уже стоит на компьютере).

```bash
cd automation
wrangler login
wrangler deploy
wrangler secret put CLOUDPAYMENTS_SECRET
wrangler secret put TELEGRAM_BOT_TOKEN
wrangler secret put TELEGRAM_ADMIN_CHAT_ID
wrangler secret put APPS_SCRIPT_URL
```
На каждую команду `wrangler secret put` он спросит значение — вставляете и
жмёте Enter. `wrangler deploy` в конце выведет адрес воркера вида
`https://vidhaya-club-payments.<ваш-аккаунт>.workers.dev` — это и есть
адрес для последнего шага.

`CLOUDPAYMENTS_SECRET` — секретный ключ (не Public ID!) из личного кабинета
CloudPayments, раздел «Настройки сайта» → «Секретный ключ для API».

### 2.4 Связать CloudPayments с воркером
Личный кабинет CloudPayments → «Настройки сайта» → **HTTP-уведомления** →
в поле «Pay» вставить адрес воркера из шага 2.3. Сохранить.

## 3. Проверка перед реальным запуском

CloudPayments даёт тестовый режим (Test mode) с тестовыми картами — включите
его в настройках сайта, сделайте пробную оплату и убедитесь, что:
- пришло сообщение в Telegram;
- появилась строка в Google Таблице;
- на тестовый email пришло письмо.

Только после этого выключайте Test mode.
