# Оплата и автоматизация — что и в каком порядке включать

Три независимых куска. Сайт (`index.html`) уже умеет открывать окно оплаты
CloudPayments - этого достаточно, чтобы принимать деньги. Всё остальное ниже
(бот-журнал в Telegram + письмо) - надстройка, можно включать позже, сайт от
её отсутствия не сломается.

Google Таблицы не используются - весь учёт оплат идёт в Telegram-чат
(бот присылает туда сообщение на каждую оплату), это и есть ваш «журнал».

## 1. Подключить приём оплаты (обязательно, чтобы кнопки вообще работали)

Уже сделано - Public ID вписан в `index.html`. Ничего дополнительно делать не
нужно, кнопки «Оплатить» уже открывают виджет CloudPayments.

## 2. Бот-журнал в Telegram (видеть все оплаты сразу в чате)

1. В Telegram напишите @BotFather → `/newbot` → следуйте подсказкам, дайте
   боту имя, например «Оплаты Внутренний путь».
2. Получите **токен бота** (`TELEGRAM_BOT_TOKEN`) - BotFather покажет строку
   вида `123456:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
3. Добавьте этого бота в чат, куда должны приходить уведомления об оплатах -
   можно создать отдельную группу «Оплаты клуба» и добавить туда бота и
   тех, кто должен видеть новые оплаты (вы, Андрей).
4. Узнайте **chat_id** этого чата: напишите в чат что угодно, затем откройте
   в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите
   `"chat":{"id":...}` в ответе - это отрицательное число для групп
   (например `-1001234567890`). Это и есть `TELEGRAM_ADMIN_CHAT_ID`.

## 3. Письмо клиенту после оплаты (необязательно, но вы просили)

Текст письма - в файле `apps-script.gs`, функция `buildWelcomeEmail`. Открыть
и поменять текст можно прямо там, обычным текстовым редактором - плейсхолдеры
`firstName` и `plan` подставляются автоматически.

1. Откройте script.google.com → New project.
2. Сотрите содержимое `Code.gs`, вставьте туда весь файл `apps-script.gs`.
3. Deploy → New deployment → Web app → Execute as: **Me**, Who has access: **Anyone**.
4. Скопируйте URL развёртывания - это `APPS_SCRIPT_URL`.
5. При первом запуске Google спросит разрешение слать письма от вашего имени -
   подтвердите под своим аккаунтом (это его же Gmail, ничего постороннего).

## 4. Сам Cloudflare Worker - связывает всё вместе

Нужен бесплатный аккаунт на cloudflare.com и `wrangler`
(`npm install -g wrangler`, если Node.js уже стоит на компьютере).

```bash
cd automation
wrangler login
wrangler deploy
wrangler secret put CLOUDPAYMENTS_SECRET
wrangler secret put TELEGRAM_BOT_TOKEN
wrangler secret put TELEGRAM_ADMIN_CHAT_ID
wrangler secret put APPS_SCRIPT_URL
```
На каждую команду `wrangler secret put` он спросит значение - вставляете и
жмёте Enter. `wrangler deploy` в конце выведет адрес воркера вида
`https://vidhaya-club-payments.<ваш-аккаунт>.workers.dev`.

`CLOUDPAYMENTS_SECRET` - секретный ключ (не Public ID!) из личного кабинета
CloudPayments, раздел «Настройки сайта» → «Секретный ключ для API».

## 5. Связать CloudPayments с воркером

Личный кабинет CloudPayments → «Настройки сайта» → **HTTP-уведомления** →
в поле «Pay» вставить адрес воркера из шага 4. Сохранить.

## Как всё это работает вместе (путь данных)

1. Человек на сайте жмёт «Оплатить», в окошке вводит имя, телефон, отмечает
   галочку про ЗК (если применимо).
2. Открывается виджет CloudPayments, человек платит картой.
3. CloudPayments после успешной оплаты сам стучится на адрес Cloudflare Worker
   (это и есть «HTTP-уведомление» из шага 5) и присылает туда все данные,
   включая то, что вы ввели в окошке (имя/телефон/ЗК) - это передаётся через
   поле `data`, которое CloudPayments просто пересылает как есть.
4. Worker проверяет, что уведомление настоящее (не подделка), и параллельно:
   - шлёт сообщение в ваш Telegram-чат (шаг 2);
   - стучится в Apps Script, который отправляет клиенту письмо (шаг 3).

Ничего из этого не требует Google Таблиц - только Telegram-чат (журнал) и
Gmail (письма), оба уже есть у вас по умолчанию.

## Проверка перед реальным запуском

CloudPayments даёт тестовый режим (Test mode) с тестовыми картами - включите
его в настройках сайта, сделайте пробную оплату и убедитесь, что пришло
сообщение в Telegram-чат и письмо на тестовый email. Потом выключите Test mode.
